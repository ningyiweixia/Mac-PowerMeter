# 架构与数据边界

## 采集

`BatteryReader` 优先读取 AppleSmartBattery 的 IOKit 属性；只有 IOKit 通道读取失败时才运行 ioreg。ioreg 使用 plist 输出，两个通道共用解析器，避免从不同字典层级抓到同名字段。

电流和电池功率使用有符号整数解释，兼容 UInt64 补码。电量通过同一字典中的 CurrentCapacity / MaxCapacity 换算；健康度使用满充容量 / 设计容量，单位为 mAh。剩余时间哨兵不作为真实时长显示。

SMC 使用 AppleSMC 用户客户端读取 B0AC、B0AV。调用检查系统返回码、结构长度、SMC 结果码和数据长度；电压与计算结果还经过合理范围和有限数值检查。整数及浮点解码适配当前 Apple Silicon 通道，sp78 固定点另按大端解码。编码样例测试不能替代每种硬件格式的现场验证。

## 主读数

电池供电时，SMC 可用则优先显示电池侧功率估算；否则使用系统负载遥测或电池估算。接电时，只有 SystemLoad 用作系统功率主读数。电池充电功率、适配器输入分别保留为明细。

`PowerSample.valid` 仅表示有可用的主功率。电量、电压、电流等字段拥有独立有效性标记；系统功率缺失不会清空有效电池信息。充电状态优先显示“充电中”，不依赖 valid。

不使用“系统遥测锚点 + SMC − 滑动均值”融合：持续的 SMC 负载变化最终会被滑动均值抵消，且两个通道没有同步标定依据。

## 监控与曲线

采集在后台串行队列运行，主线程发布状态。reading 标志防止任务堆积。主循环 Timer 支持菜单交互期间刷新，并允许有限调度容差。应用保持用户活动状态，但允许系统空闲休眠。

曲线记录真实时间戳，保留最近约 60 秒的数据，最多每 0.5 秒保存一个点。更改读取间隔不会重新解释已有数据的时间范围。充电、读取失败、数据源切换或长时间暂停后清理曲线。

曲线横坐标按时间戳绘制。数据变化时间仅表示主读数最后改变的时刻，不能单凭稳定值判断源是否陈旧。

## 界面与安装

菜单栏只显示 12pt 的功率数值与 W，或“充电中”。面板通过明确的内容尺寸与 NSPopover 同步，避免裁切。离屏预览指定浅色或深色环境，避免系统外观与预览背景不一致。

开机启动 plist 用标准属性列表序列化，正确处理路径特殊字符。保存失败会恢复开关并反馈错误。

构建使用临时目录，成功编译和签名后才替换产物。安装前验证暂存应用；旧版保存为构建目录里的 ZIP，避免应用列表出现多个备份应用。仓库不跟踪可执行文件、安装备份、工具下载或本机缓存。
